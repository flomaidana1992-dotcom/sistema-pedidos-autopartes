# Sistema inteligente de gestión y validación de pedidos de autopartes

Automatización con Make + Airtable + OpenAI + Gmail. Un pedido nuevo se valida con IA, espera aprobación humana y recién después se envía por mail al cliente.

## Contenido
- Documentacion-Sistema-Pedidos-Autopartes.pdf: arquitectura, estructura de datos, costos, seguridad y resiliencia.
- Gestión de pedidos autopartes - Final.blueprint.json: escenario 1 (validación con IA).
- Envió tras aprobación.blueprint.json: escenario 2 (envío por Gmail tras la aprobación).
- Capturas de Make: evidencias del flujo.
